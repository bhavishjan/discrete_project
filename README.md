# Item-Level Price Co-Movement Network using CPI Data
This repo is for my Discrete Structures Final Project (Semester 2) at FAST NUCES Islamabad.

I used different python libraries and tools to get reports regarding how price change of an item(s) in one city affect another city's prices. We used Discrete Structures concepts like Graphs to visualize the relationship between item on paper. For detailed infromation, see the Report.pdf.
