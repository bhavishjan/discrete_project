# Item-Level Price Co-Movement Network using CPI Data
This repo is for my Discrete Structures Final Project (Semester 2) at FAST NUCES Islamabad.

I used different python libraries and tools to get reports regarding how price change of an item(s) in one city affect another city's prices. I used Discrete Structures concepts like Graphs to visualize the relationship between different items and cosine similarity to calculate how much an item is similiar to other (two items are more similiar if both item's prices change in a similiar pattern). I used the CPI data from Pakistan Bureau of Statistics (PBS) available at [HERE](https://www.pbs.gov.pk/price-statistics/)

For detailed infromation, see the Report.pdf.
