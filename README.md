# Item-Level Price Co-Movement Network using CPI Data
This repo is for my Discrete Structures Final Project (Semester 2) at FAST NUCES Islamabad.

I with Fatima Ijaz used different python libraries and tools to get reports regarding how price change of an item in one city affect price of an itme in another city. We used Discrete Structures concepts like Graphs to visualize the relationship between different items and cosine similarity to calculate how much an item is similiar to other (two items are more similiar if both item's prices change in a similiar pattern). We used the CPI data from Pakistan Bureau of Statistics (PBS) available [HERE](https://www.pbs.gov.pk/price-statistics/)
